# Kingdoms of War website (kingdomsofwarworld.com)

Static Next.js site (`output: 'export'`), 12 languages (Turkish at `/`, the rest under `/en/`, `/de/`, ...), 22 pages per language.

- `npm run build` -> `out/` (static files). `node tools/verify-site.mjs` checks every exported page (titles, descriptions, canonical, hreflang, JSON-LD, links, assets).
- Text: `src/i18n/<lang>.ts` (all typed against `en.ts`, so a missing key fails the type check). Legal texts: `src/i18n/legal.ts` (Turkish + English; other languages show the English text).
- Civilization and age names/descriptions/unit stats come from the game data (`src/data/*.json`, generated by `npm run assets`, which reads the game repo: logos, civilization JSON and localization). Art is original and procedural (`tools/art.mjs`).
- Store links: set `STORE_URLS` in `src/lib/site.ts` when the store pages exist (buttons, JSON-LD and llms.txt switch automatically). Contact mailbox: `CONTACT_EMAIL` in the same file.
- SEO/GEO: sitemap with hreflang alternates, robots.txt (AI crawlers allowed), `/llms.txt`, `/llms-full.txt`, JSON-LD (Organization, WebSite, VideoGame, BreadcrumbList, FAQPage, CollectionPage), per-page canonical/OG/Twitter.
- Deploy: `deploy/contabo` (service `website`, domain `SITE_DOMAIN`).
